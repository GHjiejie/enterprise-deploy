# 操作表单字段与构建裁剪验证

验证日期：2026-10-24（Asia/Shanghai）。范围为库存调整、库存调拨、审批通过、驳回、复核的字段装配、依赖规则、运行时行为与生产代码裁剪。

当前目录表共 51 项能力，其中表单字段 17 项。本轮新增 9 项字段能力；企业 A 与本地交付目标上限已同步，企业 B 继续仅装配订单基础模块。

## 必填与依赖

| 操作     | 新增字段                     | 规则                                                               |
| -------- | ---------------------------- | ------------------------------------------------------------------ |
| 库存调整 | 数量、原因                   | 两项均必填；数量非零整数，绝对值不超过 100 万；保留预留库存保护    |
| 库存调拨 | 源仓商品、目标仓、数量、原因 | 四项均必填；目标字段额外依赖源仓字段；数量为正整数且不超过可用库存 |
| 审批通过 | 初审意见                     | 可选，最多 200 字；未交付或留空时使用默认意见                      |
| 审批驳回 | 驳回原因                     | 必填，去空白后 1–200 字                                            |
| 审批复核 | 复核意见                     | 可选，最多 200 字；未交付或留空时使用默认意见                      |

目录表拒绝缺失必填字段的企业清单；字段装配器还拒绝缺失的字段依赖和依赖环。运行时撤销字段许可后清除草稿，缺失必填字段时不能提交；被撤销的可选意见也不会继续进入结果。

## 裁剪证据

`tests/architecture/build.test.ts` 对代表性企业组合执行真实生产构建，并检查应用图以及每个最终文件的业务 owner。组合覆盖库存基础、完整调整、完整调拨、单独初审、单独复核、完整驳回，以及分别开启或关闭可选意见字段的版本。

生产 JS 的字节检查同时断言：

- 开启初审意见字段时包含其「初审意见须为不超过 200 字的文本。」校验器文案，关闭时不包含。
- 开启复核意见字段时包含其「复核意见须为不超过 200 字的文本。」校验器文案，关闭时不包含。
- 调拨源仓与目标仓各自拥有选项工厂和解析逻辑。关闭相应能力的合法组合不含它们的专属校验文案或业务 owner。
- 初审不引入驳回原因输入，复核不引入初审确认表单，未装配 owner 不能作为最终文件的来源。

封包后的浏览器验收另建精简初审与仅复核两个临时企业，验证未启用意见字段时没有意见输入框，仍可完成操作并写入默认记录。企业 A 则验证完整字段输入、校验反馈与审批记录。临时企业不改写实际企业清单。
