# 外部资源依赖与企业定制规则

标准版默认开放全部功能和页面。企业定制以标准版为基础，根据定制范围调整页面、功能入口、操作和展示内容。外部资源承载具体业务能力，同一资源可能被多个页面共用，同一页面也可能使用多个资源。

## 业务页面与 Mock 服务

11 类依赖全部由本地 Mock 服务支撑。用户页面按照正常业务流程组织，服务商、响应场景与调试回执留在服务层。失败和空数据通过自动化测试的会话存储夹具触发，页面没有「模拟响应」选择器。

沿用 44 个独立裁剪单元：5 个页面模块、28 个功能模块、10 个共享服务，以及 1 个公司主体模块。登录、注册、找回密码使用独立布局；认证、反馈和管理登录由各自功能模块注册独立路由。关闭能力时，对应入口、路由、表单、校验、组件和专属资源一同裁剪。

| 路由                       | 页面与业务流程                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------- |
| `/access`                  | 独立登录页，按企业配置切换短信验证码登录与微信扫码；人机验证嵌入短信登录流程，完成后进入工作台 |
| `/register`                | 手机验证、设置密码、注册成功；由手机注册模块独立交付                                           |
| `/forgot-password`         | 手机验证、设置与确认新密码、重置成功；由找回密码模块独立交付                                   |
| `/account`                 | 个人资料与安全设置，头像上传、换绑手机、注销申请、微信和邮箱绑定各自独立                       |
| `/account/personal-auth`   | 个人实名认证资料表单及认证结果                                                                 |
| `/account/enterprise-auth` | 企业资料、人脸核验、认证完成三步流程；不采集真实人脸                                           |
| `/billing`                 | 账户余额、充值金额选择、扫码支付确认、交易记录、逐笔退款、对账单下载与发票预览                 |
| `/media`                   | 图片与视频创作，结果预览、播放、文件列表及下载导出                                             |
| `/operations`              | 客户支持、通知与告警、管理安全、智能助手，按已交付能力展示页签                                 |
| `/operations/feedback`     | 客户反馈表单与提交结果                                                                         |
| `/operations/approval`     | 后台业务变更申请及审批提交结果                                                                 |
| `/admin-login`             | 独立的企业微信后台扫码登录页                                                                   |
| `/company`                 | 主体信息、开发接入示例与邮件模板，同一主体模块向登录页与页脚提供品牌信息                       |

充值完成更新本地余额和交易记录，退款更新对应交易状态。头像支持选择本地图片；图片生成使用本地 SVG 结果，视频生成使用浏览器本地录制的可播放短片；对账单与文件列表可以实际下载 CSV。Hermes 使用对话界面展示用户问题和模型回复。所有数据仅用于演示，不调用真实外部服务。

## 功能与资源的裁剪关系

功能显式依赖宿主模块和服务。例如短信登录依赖 `access` 与 `resource-sms`，缺少依赖时拒绝保存或构建。服务实现通过中立契约注入，业务模块不直接导入其他模块的实现。

关闭充值后仍可保留退款和对账单，关闭个人实名后仍可保留企业认证，关闭邮箱绑定后仍可保留邮件通知。共享服务在仍有使用功能时继续交付。

配置控制台管理企业白名单、依赖预览、构建与制品；业务应用提供上述产品页面。控制台的「外部资源（Mock）」分组管理 10 个共享服务；关闭服务时预览受影响的全部功能。单独关闭操作不会自动删除显式选中的服务。

裁剪发生在构建与交付阶段，仓库源码保留以支持其他企业。未选能力不进入该企业的源码闭包、编译图、站点文件或压缩包。运行时权限继续控制已交付能力的访问。

## 全量与定制示例

企业 A 启用全部 120 项能力，包含原有 76 项能力和本轮 44 项外部资源能力。企业 B 继续验证订单基础模块的最小交付。

`enterprise-mock-custom` 使用 17 项能力：4 个页面模块、7 个功能模块和 6 个共享服务，采用 `brand-b`。

| 定制范围                 | 页面变化                                                                   |
| ------------------------ | -------------------------------------------------------------------------- |
| 仅保留短信登录           | 登录页没有登录方式页签、注册与找回密码链接、人机验证；相应独立路由也不交付 |
| 仅保留企业认证           | 账号设置保留企业认证入口，个人实名与其他安全操作移除                       |
| 保留退款与对账单         | 费用页保留交易列表、退款与下载，没有充值和发票入口                         |
| 保留邮件通知、告警和模型 | 运维页只保留通知与告警、智能助手页签，客户支持、管理安全与对应路由移除     |
| 移除创作与主体模块       | 对应菜单、页面、登录主体展示、主体页脚和专属资源均排除                     |

标准版全量开放由完整配置表达。构建始终显式选择企业，不在配置缺失时回退到全量版本。

## 运行与验收

```bash
npm run configure
APP_ENTERPRISE=enterprise-a npm run dev
# 切换到定制版时重启开发服务
APP_ENTERPRISE=enterprise-mock-custom npm run dev

npm run check
npm run test:e2e
npm run test:console
npm run test:external
```

专项浏览器测试覆盖全部 28 个功能对应的业务流程，检查独立布局、页面跳转、验证码校验、支付与退款状态更新、文件预览与下载、对话回复、失败恢复、空数据和 390px 布局。交付测试检查被关闭功能在源码闭包、编译图、输出来源及封包内容中均不存在。

最新截图、验证结果和固定版本见 [页面与裁剪验证记录](verification-2026-10-26.md)。
